# 实验4 CSS布局实战——网站首页
Web应用开发技术实验

## 项目说明
本项目不修改HTML原始结构，仅使用CSS完成企业网站首页布局。
实现技术点：
1. Flex布局：导航栏、搜索框、banner、精品推荐、页脚模块
2. Grid布局：课程卡片二维网格布局
3. position：fixed实现固定顶部导航；relative+absolute定位
4. transition + transform：课程卡片悬浮上浮、阴影交互动效
5. 媒体查询 @media：移动端适配，课程卡片由5列变为2列

## 运行方式
VSCode打开study文件夹，使用Live Server插件打开index.html预览页面。
